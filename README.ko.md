# 인트라데이 ML 연구

[English](README.md) | **한국어**

변동성·유동성·모멘텀이 큰 주식에서 ML이 인트라데이 거래로 비용 후 수익을 낼 수 있는가?

미국 주식의 급등 후 반복 파동 관찰에서 시작해, 규칙 전략 탐색과 PPO 정책 학습으로 이어진 연구입니다. 위의 넓은 질문과 당시 실험의 더 좁은 목적을 구분해 기록했습니다.

## 핵심 결과

실행한 설정에서는 **안정적인 비용 후 수익성을 입증하지 못했습니다.**

- 모델 12개 학습, 평가 162경로 완료.
- 재진입을 허용한 일반 내부 확인 24경로 중 손실 21개, 무거래 2개, 이익 1개. 이익 경로에는 익일 청산이 포함됐습니다.
- 위험 정지가 학습 기회를 크게 줄였습니다. 학습 설계를 바꿨을 때 수익이 개선되는지는 검증하지 않았습니다.

일부 변형은 양수였지만 성과가 집중됐고, 평가 자료도 연구자가 앞서 본 자료였습니다. 모든 결과는 역사 자료와 가상 체결에 기반하며 실거래 성과가 아닙니다.
