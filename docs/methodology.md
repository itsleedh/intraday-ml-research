## 연구의 변화

처음부터 하나의 설계를 끝까지 검증한 연구가 아닙니다. 같은 개발 자료에서 질문·구현·정책을 차례로 수정한 탐색 과정입니다.

| 시점 | 변화 |
|---|---|
| 9월 24일 | 급등 후 반복 파동을 선별하는 질문에서 출발. 같은 날 RL 정책을 유지하며 수익·실패 원인을 분석하는 방향으로 발전 |
| 9월 25일 | 눌림·반등 확인을 필수 진입 조건에서 제거. 탐지 시점부터 RL이 기다림·진입·보유·청산을 선택하도록 설계 |
| 9월 27일 | 40개 개발 세션의 분봉을 조사하고, 정밀 표본을 수집해 소수 사건의 규칙 전략을 재생 |
| 9월 28일 전반 | 체결·비용 민감도를 점검한 뒤 첫 70건에서 단일 진입 규칙을 비교. 반복 규칙 B-DC는 제외 |
| 9월 28일 후반 | 고정 눌림·익절·손절·15분 보유 제한을 제거한 PPO 학습. 재진입 기여도 명시적으로 평가 |
| 9월 29일 | 비용·학습 기회·지연을 진단한 뒤 중단. 새 학습 설계는 미채택 |

초기 지도학습·LLM·다른 RL 후보와 합성 구현은 실제 시장자료에서 모두 비교한 결과가 아닙니다. 현재의 넓은 ML 질문은 당시 반복 매매 질문과 겹치지만 범위는 다릅니다.

## 실제 RL 설정

후보 필터는 가격 $2 이상, 5분 +5% 또는 15분 +8%, 해당 창의 거래대금 대용값 $100만 이상입니다. 대용값은 `Σ(low × volume)`이며 실제 체결 거래대금이나 충분한 유동성을 보장하지 않습니다.

| 항목 | 실행한 조건 |
|---|---|
| 자본·슬롯 | 블록별 $10,000, 신규 진입 예산 최대 $1,000, 매매 슬롯 1개 |
| 행동 | 5초마다 대기·후보 매수·보유 종목 매도. 공매도·레버리지·추가 매수 없음 |
| 기록 | 일반 후보 슬롯 3개, 정지 진단 1개. 청산 뒤에도 기록 유지 |
| 입력 | 최근 10분의 120프레임과 계좌·주문 상태 |
| 모델 | MLP·RNN·GRU·LSTM × seed 11·23·47 |
| 학습 | masked PPO, 14거래일 훈련 블록 2회 순회 |
| 보상 | `10,000 × 순자산 변화 / 초기자본`. 비용 반영, 거래 횟수 보너스 없음 |
| 위험 | 계좌 낙폭 5%, 포지션 손실 10%, 마감 5분 전 강제 청산 시작 |
| 주문 제한 | 후보별 매수 제출 최대 20회, 청산 보고 후 재진입 대기 5초 |

위험 정지는 블록 끝까지 이어져 다음 날짜에도 유지됐습니다. IOC의 부분 체결·미체결·정지 때문에 손실 한도나 당일 청산은 보장되지 않았습니다. 잔량은 원래 장부로 이월하며 자료가 없으면 미완료로 남겼습니다.

모든 모델은 같은 창을 받고, 각 판단에서 recurrent 기억을 초기화했습니다. 계속 기억을 이어 가는 recurrent PPO 비교는 아닙니다. PPO 설정은 γ=1, GAE λ=.99, rollout 1,024, minibatch 64, epoch 2, 학습률 .0003, clip .2입니다.

## 자료 분할과 평가

첫 70건은 앞선 규칙 탐색에서 이미 본 개발 자료입니다. 정규화는 일반 훈련 입력으로만 계산했습니다. 연도는 모두 2026년입니다.

| 역할 | 후보 수 | 계좌 기간 | 거래일 |
|---|---:|---|---:|
| 훈련 | 36 | 07-30~08-18 | 14 |
| 개발 비교 | 12 | 08-19~08-25 | 5 |
| 학습 미사용 내부 확인 | 12 | 08-26~09-01 | 5 |
| 별도 정지 진단 | 10 | 07-30~09-01 | 24 |

12개 모델 × 3평가 블록 × 2실행 조건의 72경로, 같은 가중치의 재진입 금지 72경로, 기준선 18경로로 총 162경로를 평가했습니다. 최상 seed·체크포인트를 선별하지 않았습니다.

primary/stress의 주문 도착 가정은 250ms/2,000ms이며 비용·잔량·보고 지연도 함께 바뀝니다. 비교 정책은 각각 자기 계좌로 다시 재생합니다. 50ms 판단 기준은 경제성 계산과 별도로 평가했습니다.

## 후반 수정의 상태

지연 처리 개선은 기존 모델 평가에 적용했습니다. 날짜별 학습 에피소드, 보상 단위 변경, 매수 제출 20→2회와 대기 5→60초 제안은 미채택이며 새 학습에 적용하지 않았습니다. 제약이 학습 기회를 줄인 관찰과 제약 변경의 수익 개선은 구분합니다.
